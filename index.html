    How to play

    📱
    Hold your phone sideways

    Keep the screen facing your friends, not yourself.

    💬
    Listen to the clues

    Friends describe or act out the word without saying it.

    ↓
    Correct? Flip down!

    Tilt the screen toward the floor. Return it upright for the next word.

    ↑
    Stuck? Flip up!

    Tilt the screen toward the ceiling, then return to the starting position.

    You can always use the Correct and Skip buttons, even without motion permission. Hold the phone securely; no throwing or shaking!

    Install Flip & Guess

    Play from your home screen, even when you're offline after the first visit.

    🍎
    iPhone / iPad

    Open in Safari → Share → Add to Home Screen. Enable Open as Web App if shown, then Add.

    📱
    Android

    Open in Chrome → menu (⋮) → Install app or Add to Home screen.

    💻
    Desktop

    Use the install icon in the browser address bar if available.

    This local preview supports tapping. Install and motion features need a supported browser on HTTPS or localhost.
