# Flip & Guess! 儿童翻转猜词游戏

## 功能
- 英文儿童界面，内置 6 套词库，共 150 个单词或短语。
- 每套词库可编辑、恢复默认值；可创建和删除自定义词库，支持中文、英文等 Unicode 文字。
- 30 / 60 / 90 秒计时；猜对向下翻转，跳过向上翻转；也可点击按钮，或在电脑上使用上下方向键。
- 每次翻转后回到竖直位置才能继续计分。设备方向传感器使用角度阈值、短时持续检测和防重复计分。
- 计分、词语结果、重新开始、暂停与恢复，以及可关闭的音效。
- 无外部依赖、无账号、无后端、无广告或分析追踪。词库和设置保存在当前浏览器的 localStorage 中，不会跨设备同步；清理浏览器数据后会丢失自定义内容。

## 在电脑上运行
解压后，进入包含 index.html 的目录：

```bash
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080 。本地电脑可测试按钮、词库和 PWA 缓存；普通局域网 HTTP 地址不是安全上下文，手机上的安装和运动传感器可能不可用。

## 发布网站（Cloudflare Pages 等静态主机）
将 index.html、manifest.webmanifest、sw.js 和 icons/ 放到静态站点根目录。无需 npm 或构建步骤。采用 HTTPS 公网地址访问。支持子目录部署时，也应保持这几个文件之间的相对路径。首次联网访问并完成 Service Worker 缓存后，支持离线玩；浏览器清理缓存后需要联网重新加载。

## 手机安装和操作
- iPhone：Safari 打开 HTTPS 网站，点击分享 → Add to Home Screen（添加到主屏幕），如有 Open as Web App 选项则打开。游戏开始时按需允许运动传感器权限。
- Android：Chrome 打开 HTTPS 网站，使用浏览器安装菜单，或使用页面上的 Install game 按钮（具体安装提示由浏览器决定）。
- 选择 Flip 模式，点击 Let's play，倒数时把手机横持，屏幕面向朋友并保持近似竖直。朝地面倾斜是猜对，朝天花板倾斜是跳过；每次动作后回到起始位置。不能授权时，可始终使用按钮或 Tap 模式。

## 测试与限制
- JavaScript 语法及模拟环境下的自定义词库、去重、Unicode、计分、上下翻转、防重复计分、暂停恢复和倒计时结束逻辑已通过测试。
- PWA 清单和所有图标文件均存在。当前环境阻止浏览器导航至本地站点，因此未完成真实浏览器端到端、离线安装、手机传感器或视觉测试；请部署后使用 iPhone Safari 和 Android Chrome 进行真机测试。
- 后续发布更新时，修改 sw.js 的 CACHE 版本以刷新缓存；同时避免缓存含隐私信息的服务端响应。本版无服务端数据。
